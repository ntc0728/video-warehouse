不同测试场景需要不同的配置组合：

| 配置等级 | TMDB Token | CORS 代理 | IPTV 代理 | 适用用例 |
|---------|-----------|----------|----------|---------|
| **Level 0：无配置** | 空 | 空 | 空 | HOME-001/002、SET-016、IPTV-004/005、所有"未配置"状态用例 |
| **Level 1：仅 Token** | 有效 | 空 | 空 | 首页/详情页/人物页 TMDB 数据、浏览页智能检索 |

### 代理 URL 格式参考

| 代理类型 | 配置值（设置页填入） | 实际请求格式 | 示例 |
|---------|-------------------|-------------|------|
| CORS 代理（视频采集） | `https://video-warehouse.nmziptv.top` | `{配置值}/proxy?url={encoded}` | `https://video-warehouse.nmziptv.top/proxy?url=https%3A%2F%2Fapi.example.com%2Fvideo` |
| IPTV 流代理（M3U8） | `https://iptv.nmz996.cc.cd` | `{配置值}/m3u8-proxy?url={encoded}` | `https://iptv.nmz996.cc.cd/m3u8-proxy?url=http%3A%2F%2F101.35.240.114%3A88%2Flive.php%3Fid%3DCCTV1` |
| TS 分片代理 | （由 m3u8-proxy 内部自动处理） | `{配置值}/ts-proxy?url={encoded}` | `https://iptv.nmz996.cc.cd/ts-proxy?url=http%3A%2F%2F...` |

> **注意**：CORS 代理和 IPTV 代理是两个独立的 Cloudflare Worker，部署在不同域名。代理不可用时，CMS 搜索和 IPTV 播放将失败，但 TMDB 数据（首页/详情/人物）不受影响。

## 附录：边界情况汇总

### A. 输入验证边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| 搜索关键词 | 空字符串 | 忽略，显示默认内容 |

| 搜索关键词 | 超长（>200 字符） | 不截断，正常搜索 |
| 搜索关键词 | 特殊字符 `<script>` | 不触发 XSS，正常搜索 |

| URL 输入 | 空 | 允许保存（清除） |
| 正则表达式 | 无效正则 | 显示校验错误 |
| TMDB Token | 空 | 允许保存（清除） |
| 数字输入 | 负数/小数 | 不适用（使用步进按钮） |

### C. 网络异常边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| TMDB API 超时 | 请求超过 10 秒 | AbortController 取消，显示错误 |
| CMS API 超时 | 请求超过 8 秒 | 显示错误，可重试 |
| IPTV 源超时 | M3U 文件获取超时 | 标记为不可用 |
| 代理不可达 | 代理服务器宕机 | 显示错误，可重试 |
| 部分源失败 | 28 个 CMS 源部分超时 | 已完成的源显示结果，失败的源显示错误 |
| 全部失败 | 所有请求都失败 | 显示全局错误提示 |
| 网络恢复 | 断网后恢复 | 用户可手动刷新重试 |

### D. 并发与竞态边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
