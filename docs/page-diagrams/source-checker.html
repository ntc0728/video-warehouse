✅ 源检测

/source-checker
批量检测所有 CMS 视频源的可用性、视频数量与错误信息 — 经 Video CORS 代理访问各采集站 API
统计 汇总数据
表格 CMS 源状态（真实数据）
SourceCheckerTable
数据来自 diagram-data.json 的 data.cms.sourceStatus。点击源名跳转浏览页，点击重检模拟刷新。
结构 组件树与数据流
组件树：
SourceChecker 页面 (useSettingsStore)
├── SourceStatsBar — 总源/可用/不可用/总视频数
├── SourceCheckerTable — 源状态表格
│ └── SourceRow × N — 名称 + API + 状态徽标 + 视频数 + 错误
└── BackToTopButton

数据流：
SourceChecker 页面 → useSettingsStore → sourceService → videoService.checkAllSources → CORS Proxy → CMS 采集站 API

代理端点： https://video-warehouse.nmziptv.top/proxy?url={encoded}

API URL 规则（均经 CORS 代理）：
列表：{source.api}
搜索：{source.api}?ac=videolist&wd={keyword}
详情：{source.api}?ac=videolist&ids={vod_id}
交互 交互说明
  • 1
    点击重检 — 重新请求所有源，表格显示 loading 动画videoService.checkAllSources → 逐源并发请求
  • 2
    点击源名 — 跳转到浏览页并选中该源window.location → browse.html?sourceId={id}
  • 3
    悬停行 — 高亮显示，完整 API 地址以 title 提示
