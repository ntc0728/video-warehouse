数据流 设置存储与加密流程
Settings 页面 → useSettingsStore → cryptoStore.encrypt (AES-GCM) → localStorage

加密字段： tmdbToken · baiduSecretKey · corsProxy
明文字段： theme · tmdbLanguage · selectedSources · player · iptvSources

加载流程：
启动 → 读取 localStorage → cryptoStore.decrypt → useSettingsStore.hydrate → Settings 组件 渲染真实值

TMDB Token 流程：
输入框 → DiagramCommon.setTmdbToken(v) → localStorage.setItem('tmdb_token') → 后续 fetchTMDB() 请求自动携带 Authorization: Bearer 头

Toast 系统： toast.show() 入队排队, toast.replace() 清空队列立即显示
结构 组件树
Settings (useSettingsStore)
├── TMDBSettings — Token 输入 + 语言 + 图片基址
├── VideoSourceSettings — CMS 源复选框列表 × N
├── IPTVSettings — M3U 源 + EPG 源
├── ProxySettings — Video/IPTV/CORS/M3U8/TS 端点展示
├── PlayerSettings — 解码器 + 自动播放 + 跳过片头/片尾
└── AppearanceSettings — 主题切换按钮组

辅助： Switch · ButtonGroup · InputField
