数据源 M3U 源状态
SourceStatusIndicator
展示各 M3U 播放列表源的抓取状态、频道数量。数据来自 diagram-data.json 的 data.iptv.sourceStatus。
EPG EPG 电子节目单配置
epgService
EPG 数据源（XMLTV 格式），用于匹配频道 tvgId 并显示当前节目信息。数据来自 data.iptv.epgSources。
频道 频道列表（按分组，真实数据）
IPTVChannelCard × N
按 data.iptv.groups 分组展示。每张卡片显示 logo、频道名、分组、源名称，播放按钮链接到 proxiedUrl（经 M3U8 代理）。
结构 组件树
IPTV 页面 (useIPTVStore + useSettingsStore)
├── iptv-header — 标题 + 频道总数 + 刷新按钮
├── SourceStatusIndicator — M3U 源状态标签
├── GroupPicker — 分组导航（桌面标签 / 移动端 BottomSheet）
├── iptv-content — 频道内容区
│ └── GroupSection × N（按分组分组）
│ ├── 分组标题 + 频道数量
│ └── IPTVChannelCard × M
│ ├── logo（LazyImage）
│ ├── 频道名称 + 分组 + 源名称
│ └── 播放按钮 → window.open(proxiedUrl)
└── BackToTopButton — 返回顶部
数据流 IPTV 页面数据加载流程
数据源：useIPTVStore + useSettingsStore + epgService

IPTV 页面 → useIPTVStore → iptvService → M3U 播放列表（经 Video CORS 代理获取）

EPG 节目信息 ← epgService ← EPG 数据源（XMLTV）

Store 属性 → 组件映射：
channels — 全部频道（IPTVChannel[]）→ IPTVChannelCard
groups — 分组映射（group → channels[]）→ GroupPicker + GroupSection
sourceStatus — M3U 源状态 → SourceStatusIndicator
filter — 筛选条件（keyword / group / sourceId）

频道字段：
id · name · logo · group · url(原始) · proxiedUrl(代理) · sourceName · tvgId

播放跳转：
点击播放 → window.open(proxiedUrl) → 浏览器直接播放 M3U8 代理流
