数据流 TMDB + CMS 合并
TMDB 详情（直连 CORS）：
Detail → tmdbService.getDetail(id) → TMDB API (直连，CORS 允许) → backdrop / poster / cast / recommendations / images

CMS 详情（经 video proxy 代理）：
Detail → cmsService.getDetail(vodId) → Video Proxy (https://video-warehouse.nmziptv.top/proxy?url=) → playLines[] / episodes[]

合并策略： TMDB 提供元信息(评分/简介/演员/剧照/推荐)，CMS 提供播放线路与集数 URL。 .m3u8 URL 经 CORS 代理播放，.mp4 直连播放。
