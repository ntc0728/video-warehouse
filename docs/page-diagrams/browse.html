数据流 搜索流程对比
模式一：智能检索 (mode=smart) — TMDB 直连，支持 CORS
SearchBox → useTMDBStore → tmdbService.discover() → TMDB Discover API (直连，CORS 允许)
FilterBar → genre/region/rating/sort 参数 → useTMDBStore

模式二：直链搜索 (mode=direct) — CMS 经 video proxy 代理
SearchBox → useCMSSearch → cmsService.search() → Video Proxy (CORS 代理) → 多 CMS 源并发
各源结果聚合至 useCMSSearch.cmsResults，按源分组展示

懒加载模式：
· 哨兵节点无条件渲染（不因 searchMode 条件包裹），跨状态持久
· 整页 loading 仅在首屏无数据时显示（initialLoading 区分 loading 布尔），避免加载更多时卸载网格导致滚动跳顶
