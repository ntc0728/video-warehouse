架构数据流与代理架构
代理配置：
Video Proxy (CORS) — https://video-warehouse.nmziptv.top/proxy?url= — 用于 CMS API 请求和 M3U 文件获取
IPTV Proxy (M3U8) — https://iptv.nmz996.cc.cd/m3u8-proxy?url= — 用于 IPTV 直播流代理
TS Proxy — https://iptv.nmz996.cc.cd/ts-proxy?url= — 用于 TS 分片代理

数据流：
页面组件 → Zustand Store → Service 层 → 外部 API / 本地存储

Store 列表：
useTMDBStore — TMDB 数据 + 缓存  |  useSettingsStore — 全部设置 (localStorage)  |  useIPTVStore — IPTV 频道
useUserStore — 收藏 + 历史 (IndexedDB)  |  usePlayerStore — 播放器状态

Service 层：
tmdbService — TMDB API v3  |  videoService — CMS 采集站 API  |  iptvService — M3U 解析
epgService — EPG 电子节目单  |  sourceService — 源配置加载
脚本数据获取脚本
scripts/fetch-diagram-data.mjs
通用数据获取脚本，从真实 API 获取 TMDB / CMS / IPTV 数据，输出 diagram-data.json。
用法：node scripts/fetch-diagram-data.mjs（默认获取 CMS + IPTV）
带 TMDB：TMDB_TOKEN=xxx node scripts/fetch-diagram-data.mjs
