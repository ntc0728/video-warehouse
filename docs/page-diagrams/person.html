👤 人物页

/person/:id
PersonHeader 个人资料 + MovieCredits 电影作品 + TVCredits 剧集作品 — 数据来自 TMDB API 直连
结构 组件树
Person
├── PersonHeader — profile + info (姓名/生日/出生地/知名领域/简介)
├── MovieCredits — 电影作品 (poster + title + year + character)
└── TVCredits — 剧集作品
TMDB PersonHeader — 人物详情
TMDB MovieCredits — 电影作品
数据流 tmdbService → TMDB API
Person → tmdbService.fetchPersonDetail(id) → TMDB API (直连，CORS 允许) → profile + biography
Person → tmdbService.fetchPersonMovieCredits(id) → TMDB API → movie credits
Person → tmdbService.fetchPersonTVCredits(id) → TMDB API → TV credits
