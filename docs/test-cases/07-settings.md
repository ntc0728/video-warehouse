# 6. 设置页 (Settings)

> 由 `docs/TEST-CASES.md` 拆分而来（2026-09-09 文档瘦身）。原文件已改为索引页，详情在此；修改时两处同步。

## 6. 设置页 (Settings)

**路由**: `/settings`
**核心组件**: List + Switch + Modal + ThemeSwitcher
**配置依赖**: 无需前置配置（设置页本身就是配置入口）；测试"测试连接"功能需网络

### 6.1 主题切换

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| SET-001 | 切换浅色模式 | 设置页已加载 | 点击太阳图标 | 页面主题切换为浅色，Sun 按钮高亮 |
| SET-002 | 切换深色模式 | 设置页已加载 | 点击月亮图标 | 页面主题切换为深色，Moon 按钮高亮 |
| SET-003 | 跟随系统 | 设置页已加载 | 点击显示器图标 | 主题跟随系统设置，Monitor 按钮高亮 |
| SET-004 | 主题持久化 | 切换主题 | 刷新页面 | 主题保持上次选择 |

### 6.2 TMDB 配置

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| SET-010 | 配置 TMDB Token | 设置页已加载 | 点击 TMDB Token "配置"按钮 | 打开配置弹窗 |
| SET-011 | 输入有效 Token | 弹窗已打开 | 输入 `your_tmdb_token_here` 并点击保存 | Toast 显示"TMDB Token 已保存,正在加载数据…"，自动加载首页数据 |
