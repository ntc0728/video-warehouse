# 10. 人物页 (Person)

> 由 `docs/TEST-CASES.md` 拆分而来（2026-09-09 文档瘦身）。原文件已改为索引页，详情在此；修改时两处同步。

## 10. 人物页 (Person)

**路由**: `/person/:id`
**核心组件**: PersonHeader + MovieCredits (电影/剧集 Tab)
**配置依赖**: Level 1（TMDB Token）— 人物详情和作品列表均来自 TMDB API

### 10.1 页面加载

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| PER-001 | 正常加载 | 输入有效人物 ID | 访问人物页 | 显示人物头像、姓名、又名、生日、出生地、简介 |
| PER-002 | 加载中状态 | 数据正在加载 | 查看页面 | 显示 AppLoading |
| PER-003 | 无效 ID | 输入非数字 ID | 访问人物页 | 显示"无效的人物 ID"错误 |
| PER-004 | 人物不存在 | 输入不存在的 ID | 访问人物页 | 显示"人物不存在" |
| PER-005 | API 失败 | 网络异常 | 访问人物页 | 显示错误信息 |

### 10.2 Hero 区域

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| PER-010 | 头像显示 | 有 profile_path | 查看 Hero | 显示人物头像 |
| PER-011 | 无头像 | 无 profile_path | 查看 Hero | 不显示头像区域 |
| PER-012 | 又名显示 | 有 also_known_as | 查看 Hero | 显示"又名：X / Y / Z"（最多 3 个） |
| PER-013 | 年龄计算 | 有 birthday，无 deathday | 查看元信息 | 显示"生日：YYYY-MM-DD (XX 岁)" |
| PER-014 | 已故人物年龄 | 有 birthday 和 deathday | 查看元信息 | 显示"生日：YYYY-MM-DD — YYYY-MM-DD" |
| PER-015 | 无生日 | 无 birthday | 查看元信息 | 不显示生日行 |
| PER-016 | 简介展开/收起 | 简介超长 | 点击"展开"按钮 | 简介展开，按钮变为"收起" |
| PER-017 | 简介未超长 | 简介很短 | 查看简介区域 | 不显示展开/收起按钮 |
| PER-018 | 返回按钮 | 人物页已加载 | 点击"返回" | 使用 useSmartBack 回退 |

### 10.3 作品列表 Tab

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| PER-020 | 电影 Tab | 有电影作品 | 查看 Tab 栏 | 显示"电影（X）"Tab |
| PER-021 | 剧集 Tab | 有剧集作品 | 查看 Tab 栏 | 显示"剧集（X）"Tab |
| PER-022 | 默认 Tab | 人物页已加载 | 查看默认 Tab | 默认选中"电影"（如无电影则自动切到剧集） |
| PER-023 | 无电影自动切剧集 | 电影=0，剧集>0 | 进入人物页 | 自动选中"剧集" Tab |
| PER-024 | 切换 Tab | 人物页已加载 | 点击另一 Tab | 内容切换，重置可见数量 |
| PER-025 | 作品按热度排序 | 有作品数据 | 查看列表 | 按 popularity 降序排列 |
| PER-026 | 去重 | 同一作品出现在 cast 多次 | 查看列表 | 去重后仅显示一次 |

### 10.4 作品卡片与懒加载

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| PER-030 | 作品卡片显示 | 有作品数据 | 查看作品网格 | 显示 VideoCard（海报 + 标题 + 评分） |
| PER-031 | 点击作品卡片 | 有作品数据 | 点击某作品 | 跳转到详情页 `/detail/tmdb-{type}-{id}` |
| PER-032 | 初始加载 30 个 | 作品 > 30 | 进入人物页 | 首屏显示 30 个作品 |
| PER-033 | 滚动加载更多 | 已加载首批 | 滚动到底部 | 自动追加下一批 30 个作品 |
| PER-034 | 无作品 | 电影和剧集都为空 | 查看 Tab 栏 | 不显示任何 Tab |
| PER-035 | 文档标题 | 人物页已加载 | 查看浏览器标签 | 显示人物名称 |
