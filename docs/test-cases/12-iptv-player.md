# 11. IPTV 播放页 (IPTVPlayer)

> 由 `docs/TEST-CASES.md` 拆分而来（2026-09-09 文档瘦身）。原文件已改为索引页，详情在此；修改时两处同步。

## 11. IPTV 播放页 (IPTVPlayer)

**路由**: `/iptv/play?url=...&id=...&name=...`（独立顶层路由，不走 AppLayout Keep-Alive）
**核心组件**: UniversalPlayer (platform 模式)
**配置依赖**: Level 3（全配置）— 需 IPTV 代理 + 频道数据

### 11.1 页面加载与频道匹配

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| IPTVP-001 | 正常播放 | URL 参数含有效频道 URL | 访问 IPTV 播放页 | UniversalPlayer 加载并播放频道流 |
| IPTVP-002 | 频道匹配（ID 精确） | URL 参数含 `id` | 访问播放页 | 按 ID 精确匹配频道 |
| IPTVP-003 | 频道匹配（名称） | URL 参数含 `name`，无 `id` | 访问播放页 | 按名称匹配频道 |
| IPTVP-004 | 频道匹配（URL） | URL 参数仅含 `url` | 访问播放页 | 按 URL 直接匹配频道 |
| IPTVP-005 | 频道匹配（代理 URL） | URL 是代理格式 `/m3u8-proxy?url=...` | 访问播放页 | 从代理 URL 中提取原始 URL 进行匹配 |
| IPTVP-006 | 无匹配频道 | URL 参数的频道不存在 | 访问播放页 | 显示错误或空状态 |
| IPTVP-007 | 空 URL 参数 | 无 url 参数 | 访问播放页 | 显示空播放器或错误提示 |
| IPTVP-008 | 返回按钮 | IPTV 播放页已加载 | 点击返回 | 回退到 IPTV 列表页（useSmartBack） |

### 11.3 裸流降级识别（D1）

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| IPTVP-020 | 裸流自动降级 | 频道 URL 为裸 TS/FLV（无扩展名或被误判 m3u8） | 播放该频道 | HLS 解析失败后自动重建 mpegts.js 重试同一 URL，toast「检测到裸流，切换解码方式重试…」，不弹全屏错误 |
| IPTVP-021 | 降级每 URL 仅 1 次 | 裸流降级后 mpegts.js 仍失败 | 观察 | 不重复降级，转入 C1 自动切线路 / A3 切代理兜底 |
| IPTVP-022 | 代理裸流透传 | 裸流走 m3u8-proxy | 播放 | worker 对非 #EXTM3U 内容直接透传二进制（不重写、不缓存），mpegts.js 可拉流 |
| IPTVP-023 | manifestLoadError 不降级 | 源站 403/超时（网络层失败） | 播放 | 报「频道源不可用」走 A3 兜底，不触发裸流降级 |

### 11.4 Toast 全局系统（2026-08-05 整改）

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| TOAST-001 | 普通页面位置 | 非播放器页面（如设置页） | 触发任意 toast | 顶部居中、位于导航栏（--header-height）下方，宽度 min(22rem, 视口-2rem)，文本居中 |
| TOAST-002 | 播放器页面位置 | 播放页 / IPTV 播放页 | 触发任意 toast | 播放器中间靠上（body[data-player-toast] → top 42%），不贴播放器边框 |
| TOAST-003 | 三种类型图标 | 任意页面 | 触发成功/警告/错误 toast | 分别显示绿勾/橙三角/红感叹号图标，图标与文本同高（--icon-* token） |
| TOAST-004 | 统一 3s | 任意页面 | 触发 toast 并等待 | 约 3s 后自动消失（toastBus TOAST_DURATION=3000） |
| TOAST-005 | IPTV 切线路提示 | IPTV 播放页有同名多线路 | OSD 切换线路 | 右上角提示「已切换到线路 X/Y」；C1 自动切换提示「该源仅含音频，已自动切换线路…」 |
| TOAST-006 | 首帧不误报 | 播放页首次加载 | 观察右上角提示 | 初始加载不显示「已切换」类提示（ToastTrigger 首帧 src 守卫） |
| TOAST-007 | 播放器操作提示右上角 | play 页视频可播 | 点击播放/暂停、调音量、切集/线路 | 右上角 .up-player-toast 显示对应操作信息（播放/暂停/音量/已切换），3s 消失；与全局错误 toast（中间靠上）分离 |
| TOAST-008 | 放大图标右下角 | 非 TV 端 IPTV 播放页 | 观察 | 放大图标位于右下角（非右上角 header） |
