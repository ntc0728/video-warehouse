# 3. 详情页 (Detail)

> 由 `docs/TEST-CASES.md` 拆分而来（2026-09-09 文档瘦身）。原文件已改为索引页，详情在此；修改时两处同步。

## 3. 详情页 (Detail)

**路由**: `/detail/:id`
**核心组件**: Hero + TabBar + CastList + StillsLightbox + VideoCard 推荐
**配置依赖**: TMDB 详情需 Level 1（Token）；播放列表 Tab 需 Level 2（Token + CORS 代理）
