## 13. 页面交叉跳转交互测试

> 覆盖所有页面间的跳转路径，验证 state 传递、来源追踪、回退行为、数据连续性。
> 核心机制：`useSmartBack` 回退优先级 → state.from > state.fallback > 参数 fallback > history(-1) > 兜底首页
> **配置依赖**: 大部分用例需 Level 3（全配置）；深链回退用例可仅需 Level 1

### 13.11 路由切换即时性验证（Keep-Alive 模式，无 View Transitions）

> 历史背景：原使用 View Transitions API 做 cross-fade，但 Keep-Alive 模式下 DOM 切换本就 ≈1ms，
> 整页快照反而成为开销主因（移动端尤其明显），已彻底移除。下列用例验证切换即时性 + 状态保持。
