# 附录：边界情况汇总

> 由 `docs/TEST-CASES.md` 拆分而来（2026-09-09 文档瘦身）。原文件已改为索引页，详情在此；修改时两处同步。

## 附录：边界情况汇总

### A. 输入验证边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| 搜索关键词 | 空字符串 | 忽略，显示默认内容 |
| 搜索关键词 | 纯空格 | trim 后为空，忽略 |
| 搜索关键词 | 超长（>200 字符） | 不截断，正常搜索 |
| 搜索关键词 | 特殊字符 `<script>` | 不触发 XSS，正常搜索 |
| 搜索关键词 | emoji 表情 | 正常搜索 |
| URL 输入 | 无效格式 | 显示校验错误 |
| URL 输入 | 空 | 允许保存（清除） |
| 正则表达式 | 无效正则 | 显示校验错误 |
| TMDB Token | 空 | 允许保存（清除） |
| 数字输入 | 负数/小数 | 不适用（使用步进按钮） |

### B. 状态边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| 数据源选择 | 视频源取消到最后 1 个 | Toast 提示"至少保留一个"，不允许取消 |
| 数据源选择 | 视频源选择超过 6 个 | Toast 提示"最多 6 个"，不允许选择 |
| IPTV 源选择 | 超过 3 个 | Toast 提示"最多 3 个" |
| EPG 源选择 | 超过 3 个 | Toast 提示"最多 3 个" |
| 计数器 | 片头时长到最小值 10 | "-"按钮 disabled |
| 计数器 | 片头时长到最大值 300 | "+"按钮 disabled |
| 计数器 | EPG 更新间隔到 1 | "-"按钮 disabled |
| 计数器 | 刷新间隔到 72 | "+"按钮 disabled |

### C. 网络异常边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| TMDB API 超时 | 请求超过 10 秒 | AbortController 取消，显示错误 |
| CMS API 超时 | 请求超过 8 秒 | 显示错误，可重试 |
| IPTV 源超时 | M3U 文件获取超时 | 标记为不可用 |
| 代理不可达 | 代理服务器宕机 | 显示错误，可重试 |
| 部分源失败 | 28 个 CMS 源部分超时 | 已完成的源显示结果，失败的源显示错误 |
| 全部失败 | 所有请求都失败 | 显示全局错误提示 |
| 网络恢复 | 断网后恢复 | 用户可手动刷新重试 |

### D. 并发与竞态边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| 快速切换 Tab | 在详情页快速切换 Tab | 仅渲染当前 Tab 内容 |
| 快速搜索 | 连续输入不同关键词 | 仅最后一次搜索生效（防抖） |
| 快速切集 | 连续点击不同集数 | 仅最后一次点击生效 |
| 页面离开时取消请求 | 正在加载时离开页面 | AbortController 取消未完成的请求 |
| Keep-Alive 切回 | 从其他页面切回 | 组件不卸载，状态保持 |
| CMS 防抖 | 快速切换 Tab 触发 CMS 加载 | 2 秒内不重复请求 |

### E. 存储边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| IndexedDB 满 | 存储空间不足 | 操作失败时 catch 错误，不崩溃 |
| localStorage 满 | AES-GCM 加密数据写入失败 | 设置操作失败，不崩溃 |
| 历史记录过多 | 积累 1000+ 条历史 | 正常显示（懒加载分批渲染） |
| 收藏过多 | 积累 500+ 收藏 | 正常显示（懒加载分批渲染） |

### F. 路由与导航边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| 直接访问详情页 | 浏览器地址栏输入 `/detail/tmdb-movie-123` | 正常加载详情页 |
| 直接访问播放页 | 浏览器地址栏输入 `/play/tmdb-movie-123` | 正常加载播放页 |
| 直接访问 IPTV 播放页 | 浏览器地址栏输入 `/iptv/play?url=...` | 正常加载 IPTV 播放页 |
| 无效路由 | 访问不存在的路径 | 显示 404 或重定向到首页 |
| ID 格式变化 | `tmdb-movie-123` vs `tmdb-tv-456` vs 纯数字 ID | 正确解析 mediaType 和 TMDB ID |
| ID 含特殊字符 | `tmdb-movie-123-extra` | parseInt 只取第一段数字，多余部分忽略 |

### G. 平台边界

| 场景 | 边界情况 | 预期处理 |
|------|---------|---------|
| isNativePlatform | 原生平台（如 Capacitor） | Player 使用 compact 模式 |
| TV 端空间导航 | TV 遥控器操作 | useSpatialNavigation 生效，焦点在卡片间移动 |
| 移动端触摸 | 触摸滑动、捏合 | 正常交互，无桌面端 hover 效果 |
