# 2. 浏览/搜索页 (Browse)

> 由 `docs/TEST-CASES.md` 拆分而来（2026-09-09 文档瘦身）。原文件已改为索引页，详情在此；修改时两处同步。

## 2. 浏览/搜索页 (Browse)

**路由**: `/browse`
**核心组件**: SearchBox + FilterBar + SortBar + BrowseGrid（双卡片布局）
**配置依赖**: 智能检索需 Level 1（Token）；CMS 直链搜索需 Level 2（Token + CORS 代理）

### 2.1 搜索模式切换

| 编号 | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|------|---------|---------|---------|---------|
| BROWSE-001 | 默认智能检索模式 | 进入浏览页 | 查看搜索区域 | 默认选中"智能检索" Tab，显示 FilterBar |
| BROWSE-002 | 切换到直链搜索 | 智能检索模式 | 点击"直链搜索" Tab | 切换到 CMS 搜索模式，FilterBar 隐藏，显示 SourceStatusIndicator |
| BROWSE-003 | 切换回智能检索 | 直链搜索模式 | 点击"智能检索" Tab | 切换回 TMDB 模式，FilterBar 重新显示 |
| BROWSE-004 | 切换模式保留搜索词 | 已输入搜索词 | 切换搜索模式 | 搜索词保留，自动用新模式重新搜索 |
