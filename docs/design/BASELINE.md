# 基础设计规范基线 v1（KinoTV）

> **生效日期**：2026-09-15
> **上游**：《[三端设计规范审查报告](../DESIGN-REVIEW-2026-09-15.md)》→《[实施方案](../DESIGN-PLAN-2026-09-15.md)》

> **口径**：本项目三端 = 移动端（<768，含 app 恒移动）/ 桌面端（768–2200，≥2200 内容区封顶）/ TV（`[data-device="tv"]`，1080p = A、4K = 2A）。

## 一、文字语义四档（硬契约）

| token | 浅色 | 对比度（白卡 / 页面底） | 暗色 | 对比度（#1f1f1f / #141414） | 允许用途 |
| --- | --- | --- | --- | --- | --- |
| `--color-text` | `#000` | 21.00 / 19.26 | `#fff` | 16.48 / 18.42 | 标题、正文、可点文本 |
| `--color-text-secondary` | `#666` | 5.74 / 5.27 | `#a0a0a0` | 6.30 / 7.04 | 次要信息、表单标签、时间戳 |
| `--color-text-tertiary` | `#6b6b6b` | 5.33 / 4.89 | `#8c8c8c` | 4.90 / 5.48 | 辅助说明、单位、补充信息 |
| `--color-text-disabled` | `#bfbfbf` | 1.84 / 1.69 | `#5a5a5a` | 2.39 / 2.67 | **仅**禁用态、占位符、纯装饰图标 |

> **红线**：只有「禁用 / 占位 / 纯装饰」允许低于 4.5:1（WCAG 2.2 AA 正文档）。其余一律 ≥4.5:1。
> **反例（已修）**：原 `tertiary = #999` 仅 2.85:1，却全站消费 167 处且多用于承载信息 → 呈现「灰蒙蒙」。

## 二、状态色双档（fill 只管填充，text 才承载信息）

| 语义 | fill（填充/描边） | `*-text`（文字/图标，浅色） | 白底 | `#f5f5f5` 底 | 白字 on it | 暗色 `*-text` |
| --- | --- | --- | --- | --- | --- | --- |
| success | `#52c41a` | `#237804` | 5.59 | 5.12 | 5.59 | `#73d13d` |
| warning | `#fa8c16` | `#a05c00` | 5.22 | 4.78 | 5.22 | `#d89614` |
| error | `#ff4d4f` | `#cf1322` | 5.57 | 5.11 | 5.57 | `#ff7875` |
| info | `#1677ff` | `#0958d9` | 6.16 | 5.65 | — | `#3c9ae8` |
| danger（仅 LIVE / 危险） | — | `#cf1322` | 5.57 | 5.11 | 5.57 | `#cf1322` |

> **规则**：`--color-*`（fill 档）**不得**直接用于文字或承载信息的图标 —— 它们在白底上只有 2.27–4.10:1。
> **颜色语义**：红色**只**表示「危险 / LIVE」；年份、类型等中性标签一律用中性底（见下）。

## 三、封面角标（.badge-chip）

叠在封面图 / 视频帧上的角标统一为**中性深玻璃底 + 白字**：

```css
background: rgba(0, 0, 0, 0.6);  /* 跨主题一致，不随 [data-theme] 翻转 */
color: #fff;                      /* 任意封面图下最坏 5.74:1（纯白底算） */
```

| 底图 | 白字对比度（α=0.6） |
| --- | --- |
| 纯白封面（最坏） | 5.74 ✅ |
| 浅灰 `#c8c8c8` | 8.06 ✅ |
| 中灰 `#808080` | 12.63 ✅ |
| 深灰 / 黑 | 18.42 / 21.00 ✅ |

> **为什么不用彩色底**：任何「半透明彩底 + 白字」的对比度都取决于封面图（不可控），浅色封面上可低至 2.04:1。色义改由 `.badge-chip__dot` 圆点或图标颜色承载。

## 七、改动护栏

1. 颜色**只能**来自 token；新颜色先进 `variables.css` 并核算对比度（见第八节脚本）。
2. 封面角标一律 `.badge-chip`；不能用彩色底 + 白字承担语义。
3. 字号只用 `--text-*`；**禁止裸 px**（stylelint 已强制）。
4. 布局尺寸**禁止 100vw / 100vh**（改 `100%` / `100dvh`；全出血场景需 `stylelint-disable-next-line` 显式豁免并说明理由）。
5. 新增桌面样式默认放 `@media (width >= 1024px)`；TV 覆盖集中在 `[data-device="tv"]` 块。
6. 观感类改动必须附可双击打开的对照 demo（`changelogs/demos/`）。
7. `npm run build` 必须通过（本地沙箱清 dist 撞批量删除保护时用 `npx tsc -b && npx vite build --emptyOutDir false`）。
8. **护栏命令**（详见 [a11y-CHECKLIST.md](./a11y-CHECKLIST.md) §A）：

   ```bash
   pnpm run lint          # ESLint：className / style={{}} / 颜色常量里的裸 hex、Tailwind 默认调色板
   pnpm run lint:design   # design-audit：CSS 层裸 hex / fill 档误用 / 裸 z-index / 字重 800-900（基线棘轮）
   ```

   `lint:design` 用**基线棘轮**：存量违规快照在 `scripts/design-audit-baseline.json`，只拦新增。
   清了历史债后跑 `node scripts/design-audit.mjs --update-baseline` 收紧基线。

## 八、对比度自检（WCAG 2.2）

```js
const srgb = (c) => (c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4);
const lum = ([r, g, b]) => 0.2126 * srgb(r / 255) + 0.7152 * srgb(g / 255) + 0.0722 * srgb(b / 255);
const ratio = (a, b) => (Math.max(lum(a), lum(b)) + 0.05) / (Math.min(lum(a), lum(b)) + 0.05);
// 正文 ≥4.5:1；大字（≥18.66px 或 ≥24px）≥3:1；UI 组件/图形边界 ≥3:1
```
