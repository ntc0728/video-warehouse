# Triage 标签

工程技能使用五个标准 triage 角色。本文件将这些角色映射到本仓库 issue 跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库的标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估此 issue |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 描述完整，agent 可直接开工 |
| `ready-for-human` | `ready-for-human` | 需要人类实现 |
| `wontfix` | `wontfix` | 不处理 |

当技能提到某个角色时（如"应用 AFK-ready 标签"），使用本表中对应的标签字符串。

可编辑右列以匹配你实际使用的标签名。
