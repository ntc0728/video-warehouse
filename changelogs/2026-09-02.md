## 1. HLSAdapter 缓冲策略：动态预加载 → 固定 90MB 上限 + 直播低延迟

- 日期：2026-09-02
- 问题：原实现用 `getBufferLength` + `preloadTimer` + `baseBufferLength`/`startPreload`/`stopPreload` 手动管理缓冲，逻辑脆弱、直播缓冲收敛不及时。
- 旧逻辑：`src/components/UniversalPlayer/adapters/HLSAdapter.ts` 里手维护预加载定时器与基础缓冲长度，ABR 默认估算偏低，弱网易频繁卡顿。
- 新逻辑：移除整套动态预加载逻辑；`hls.js` 配置改为
  - `maxBufferSize: 90 * 1024 * 1024`（90MB 硬上限，hls.js 自动在 30s~600s/回看区间管理缓冲，见 `:80` 注释）；
  - `abrEwmaDefaultEstimate: 1500000`（1.5Mbps 起跳，弱网首段更稳）；
  - 直播分支在 `LEVEL_LOADED` 收敛缓冲并吸收低延迟参数。
- 涉及文件：`src/components/UniversalPlayer/adapters/HLSAdapter.ts`（`maxBufferSize` `:81`、`abrEwmaDefaultEstimate` `:84`）
- 构建：`npm run build` 通过；Vitest 383 通过；player E2E 全绿。

## 2. MPEGTSAdapter：点播/直播分支 + 断流重连

- 日期：2026-09-02
- 问题：mpegts.js 适配层只有单一直播配置，点播（FLV/TS 直链）不支持 seek，直播断流不重连。
- 旧逻辑：`MPEGTSAdapter` 固定按直播初始化，无 `isLive` 分支、无 ERROR 重连、无点播 seek。
- 新逻辑（`src/components/UniversalPlayer/adapters/MPEGTSAdapter.ts`）：
  - `isLiveMode = options?.isLive ?? true`（`:33`），构造函数透传 `:30`；
  - 直播（`isLive=true`）：低延迟配置、不支持 seek、ERROR 后 2s 重试 `unload→load→play`，最多 `MAX_RECONNECT_COUNT = 5` 次（`:19`）并 toast 提示（`:81`~`:86`）；
  - 点播（`isLive=false`）：正常缓冲、支持 seek、失败不重连（走上层切线路/切源）；
  - `destroy()` 清理 `reconnectTimer`（`:147`~`:149`）。
- 涉及文件：`src/components/UniversalPlayer/adapters/MPEGTSAdapter.ts`
- 构建：`npm run build` 通过；playwright MPEGTS 点播/重连用例通过。

- 涉及文件：`src/services/vodParser.ts`、`src/services/vodParser.test.ts`
- 构建：Vitest 383 通过。

## 5. UniversalPlayer：点播裸流降级 + isLive 透传

- 日期：2026-09-02
- 问题：点播 FLV/TS 直链（detectSourceType 误归 m3u8）解析失败无兜底；MPEGTS 分支拿不到 isLive 状态。
- 旧逻辑：`type` 选择仅在 `mode==='iptv'` 下用 `currentType`，VOD 不启用裸流降级；`usePlayerCore` 未收到 `isLive`。
- 新逻辑（`src/components/UniversalPlayer/UniversalPlayer.tsx`）：
  - 裸流降级（D1，` :518`~`:532`）：HLS `manifestParsingError → BARE_STREAM` 时 `setDegradedType('flv')`（` :528`）重试同一 URL（每 URL 仅 1 次防环）；点播与 IPTV 均启用；
  - `type` 选择（` :585`）：`degradedType ?? (mode === 'iptv' ? currentType : type)`；
  - `isLive` 透传（` :595`）：`isLive: mode === 'iptv'`（VOD 为 false → MPEGTS 走点播分支）；
  - A3 直播直连失败自动切代理（` :535`）。
- 涉及文件：`src/components/UniversalPlayer/UniversalPlayer.tsx`、`src/components/UniversalPlayer/usePlayerCore.ts`、`src/components/UniversalPlayer/adapters/adapterRegistry.ts`
- 构建：`npm run build` 通过；player E2E 全绿。
