## 1. LazyImage placeholder 加载时不露白（transition:none + solid背景兜底）

- 日期：2026-08-23
- 问题：图片加载时短暂露白色背景，而非持续显示 shimmer 骨架。根因是 `.lazy-image-container.loaded .lazy-image-placeholder` 隐式继承父级 transition，placeholder 先淡出，而 img 的 blur-up fade-in 需 ~0.6s，两者不同步 → 时间窗口内两图均不可见 → 白底。另 `.lazy-image-skeleton` 只有 gradient 无 solid 兜底，浏览器尺寸异常时 gradient 不渲染即露白。
- 旧逻辑：
  - `LazyImage.css` `.lazy-image-container.loaded .lazy-image-placeholder` 仅有 `opacity: 0`，无 `transition:none` → 默认 transition（可能为父元素 0.3s 淡入）延迟 placeholder 消失。
  - `.lazy-image-skeleton` 仅 `background: linear-gradient(...)` 无 solid 底色。
- 新逻辑：
  1. `.loaded .lazy-image-placeholder` 显式加 `transition: none`，placeholder 与 img fade-in 同时消失/出现，消除时间差。
  2. `.lazy-image-skeleton` 加 `background-color: var(--color-placeholder-shimmer-a)` 作为 gradient 失效时的兜底实色。
- 涉及文件：`src/components/LazyImage/LazyImage.css`
- 构建：`pnpm run build` 通过
- 验证：home 45/46 过（HOME-060 预存 flaky，clean master 同 fail，无关）

## 2. 首页卡片封面滚动触发加载 + preload 顺序修复

- 日期：2026-08-23
- 问题：① 所有分类数据一次性加载完后再展示，页面初始化期间所有卡片封面同时加载，首屏体验慢；② `preloadRowCovers` 先标记 w342 缓存再加载 w185，但 w185 还未完成时 w342 缓存标记会误导后续 LazyImage 进入「已加载」态导致跳过实际加载。
- 旧逻辑：
  - `Home/index.tsx` useEffect 中调用 `preloadRowCovers(cat.rows)` 预加载所有行封面（w185+w342）。
  - `preloadRowCovers.ts`：先 `markImageLoaded(cacheKeys)`（w342），再 `img.src=loadUrls`（w185）。但 w342 先标为 loaded，若 w185 还在加载中，LazyImage 会误认为已加载完毕。
  - 所有 TMDBMovieRow 的 LazyImage 立即开始加载（无 scroll 触发）。
- 新逻辑：
  1. `LazyImage.tsx` 新增 `disabled` prop：为 true 时跳过 IntersectionObserver、强制 `isInView=false`，外部组件控制何时允许加载。
  2. `VideoCard.tsx` 新增 `imageDisabled` prop，透传给 LazyImage 的 `disabled`。
  3. `TMDBMovieRow/index.tsx`：对 `.tmdb-movierow-header` 建立 IntersectionObserver（rootMargin 100px，threshold 0），标题进入视口后设 `isHeaderVisible=true`，传入 `imageDisabled={!isHeaderVisible}` 到每张卡；分类切换时（scrollResetToken 变化）重置 `isHeaderVisible=false` 并重建 Observer。
  4. `Home/index.tsx`：移除 useEffect 中的 `preloadRowCovers` 调用，改由滚动触发替代。
  5. `preloadRowCovers.ts`：将 `markImageLoaded(cacheKeys)` 移至 `img.src=loadUrls` **之后**，保证 w185 加载中时 w342 缓存尚未被错误标记。
  6. `Home/index.tsx` 同步将 `.home-skeleton-hero` 外层改为 `.hero-banner__card` 包裹（与其他页面 banner 骨架结构对齐）。
- 涉及文件：`src/components/LazyImage/LazyImage.tsx` / `src/components/VideoCard/VideoCard.tsx` / `src/components/TMDBMovieRow/index.tsx` / `src/pages/Home/index.tsx` / `src/pages/Home/preloadRowCovers.ts`
- 构建：`pnpm run build` 通过
- 验证：home 45/46 过（HOME-060 预存 flaky）
