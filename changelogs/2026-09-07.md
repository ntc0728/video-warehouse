## BR-C「filter-bar 与顶部巨大间距」根因定案 + 真实拟真 Demo V3（2026-09-07 追加）

> 用户反馈三点：① 筛选面板与顶部元素巨大间距；② demo 未考虑智能检索/直链搜索双模式；③ 「类型」未单独成行。已全部定位并产出 V3 demo：`demos/demo-ultrawide-browse-brc-v3-2026-09-07.html`（可滚动舞台 + Bug/修正一键对比）。

### ① 巨大间距根因（定案）

- BR-C 块（Browse.css:308 起）`grid-template-areas: 'tabs results' / 'filters results'`，两条行轨道均为隐式 **auto**，而 `.browse-card--results` 通过 areas **横跨两行**。
- CSS Grid 把跨行项目的剩余高度**平均分配进所跨的行**：结果区 ~2400px、筛选面板 ~600px → 多出 ~1800px 摊进 row1 → row1 从 46px 被撑到 660px+（headless 实测 660）。tabs 元素因 `align-items:start` 自身保持 46px，空隙出现在 tabs 下方 → 即用户所见「面板与顶部元素巨大间距」。
- **修复（一行，待拍板后落地）**：BR-C 块 grid 加 `grid-template-rows: auto minmax(0, 1fr);` —— row2 吸收跨行剩余高度，row1 恒 46px。直链搜索模式（FilterBar 条件渲染不存在，index.tsx:377）同式成立。
- 附带发现：**Tab 通栏变体**（`'tabs tabs' / 'filters results'`）下 results 不跨行，天然免疫此 Bug，可作另一条修复路径（demo 内可切换对比）。

### ② V3 demo 对齐真实结构

## 首页超宽对齐 + CQA 封面放大（2026-09-07，拍板后落地）

### 根因定案

1. **cqa-overlay `max-width` 百分比基准 bug（CategoryQuickAccess.css:299-300）**：overlay 是 `position:fixed`，`max-width: var(--layout-content-max-width)` 的 `100%` 按**视口**解析；页面内容同 token 的 `100%` 是**减 page-pad-x 后的内容盒**。→ <2280 视口下面板比内容宽 2×pad（1920 实测 1920 vs 1760，顶到屏幕边、网格与下方卡片错 80px），仅 ≥2560 碰巧对齐。**修复**：`left/right: 0` → `var(--page-pad-x)`，面板宽度恒 ≡ 内容宽度。
2. **hero 在 2200 封顶之外（Home/index.tsx:408）**：HeroBanner（宽屏委托 HeroBili）挂 `.home-page__content` 外（规避祖先 transform 动画层），不受 2200 上限 → ≥2200 视口 hero 比下方模块宽 2×半 pad（2560 实测 2280 vs 2200，错位 40px/边）。**用户拍板：hero 也收口 2200**。Home.css 新增 `.home-page > .hero-banner__card, .home-page > .hero-bili { width:100%; max-width: var(--layout-content-max-width); margin-inline:auto }`（:not(tv) 前缀）。
   - ⚠️ **flex 子项坑**：.home-page 是 flex column，子项只写 `margin-inline:auto + max-width` 而 width:auto → 按 fit-content 收缩（2560 实测 hero 被压到 1117px）。必须显式 `width:100%` 先撑满再封顶（与 .home-page__content 同构）。
   - 骨架镜像：`.home-page.home-skeleton > .home-skeleton-rows` 同步封顶，避免进入动画期间骨架条比真实内容宽。
3. **封面 120×68 → 150×85**（等比 1.25×，16:9 不变，hotcard/catcard 共用）：新增 `--cqa-poster-w/h: 150px/85px` 定义在 `.cqa-overlay,.cqa-heat-row` 双宿主；`--cqa-row-h` 改由 `--cqa-poster-h` 派生。
