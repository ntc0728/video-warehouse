# reference-transaction 自愈：引用未落盘当场补写，不再等手动救

## 旧 ↔ 新

| | 旧 | 新 |
| --- | --- | --- |
| 未落盘引用 | 只告警，等人 node 手补 | **当场按事务期望 SHA 补写 loose ref**（直写文件，不走 git 引擎防递归） |
| 复验 | 值比对（rev-parse 假绿可骗过） | 值比对 + `git cat-file -e` 对象存在性 |
| 对象缺失 | 无法识别 | 报「对象库受损」，明确指向 .git 换血流程 |

## 关键发现（假绿新形态）

`git rev-parse --verify` 对「ref 文件内容是 40 位 hex 但对象库无此对象」**不报错、照常回显该 SHA、exit 0**。
首版自愈复验因此被 deadbeef 假成功骗过；一切 ref 校验必须叠 `git cat-file -e`。

## 实测

1. 缺失 + 合法 SHA → `⚡ 已自动补写`，rev-parse 复验一致。
2. 非法/缺对象 SHA → 补写后复验 `cat-file -e` 失败 → ❌ 报警（不再假成功）。
3. 真实仓库无回归（`repo-health-check` → ✓ ok）。
