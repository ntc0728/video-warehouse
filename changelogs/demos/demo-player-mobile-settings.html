实现对照说明（本次 Demo 覆盖的 4 项改动）
  • ① 启动封面：`capacitor.config.ts` 移除蓝色 `backgroundColor`；`android-res-patch` 增加 `values-night-v31`（深色 `windowSplashScreenBackground`），`generate-icons.mjs` 从 `public/icon.svg`（1024 矢量）生成白底/黑底两套 `splash.png`（`drawable-*` 与 `drawable-night-*`），Android 资源限定符自动按设备主题选择。
  • ② 右上角操作提示移除：仅对移动/App 端 `/play` 点播页关闭 `ToastTrigger` 的播放/暂停/音量/倍速/循环/PiP/镜像/比例/解码订阅（IPTV 直播页保留）。
  • ③ 控制栏整改：隐藏倍速（含文字）、上/下集、音量、循环；`PiPButton` 与「更多设置」移入 `PlayerHeader` 右上角（画中画 · 投屏 · 更多），控制栏仅剩播放/暂停 + 进度条 + 时间。
  • ④ 更多设置弹窗：替换原 `MoreMenu` 悬浮菜单为底部 `BottomSheet`，全部设置项为卡片布局，含倍速/循环/定时关闭/后台听视频/字幕（右侧开关=开启/关闭字幕，视频支持字幕时才可控制；下方「字幕设置」子项在字幕关闭时隐藏，开启时显示）/镜像/画面比例；字幕设置二级弹窗含「双语字幕+大字号」与「翻译语言(百度翻译AI)」。
  • 投屏（DLNA）：本 Demo 仅覆盖 UI + 状态机（搜索动画 → 设备列表 → 连接中 → 已连接控制面板 → 断开）；Android 原生模块（SSDP 设备发现 + `SetAVTransportURI/Play/Pause/Seek` 推送）作为独立任务后续实现。投屏期间右上角图标常亮提示连接中。
