现状：四层压成两层近似灰

页面底 #f5f5f5　扫光 #ececec　#dcdcdc　占位 #e9e9e9
模块底（tag/分页）也 = #f5f5f5，与页面底完全同值 → 整页"灰糊"。

方案一：白页 + 灰模块 + 中灰骨架，层层面面拉开

页面底 #fff　模块 #f5f6f8　扫光 #f3f4f7↔#e8ebf1　占位 #f0f2f6
纯白页底上，轻灰模块与中灰骨架一眼分层；灰度已按反馈整体提亮半档，避免"太深"。
层级 token现状（浅/暗）方案一（浅/暗）说明
页面底 --color-background#f5f5f5 / #141414#ffffff / #121215浅色升纯白；暗色微偏冷黑（比现状深一点点让 surface 跳出，不过沉）
内容面 --color-surface#fff / #1f1f1f#ffffff / #1e1f23浅色与页面同白（靠阴影/边框分界）；暗色与页底拉开层次
模块底 tag/收藏/分页#f5f5f5(=页底) / #262626#f5f6f8 / #232528灰专属模块语义，白页上清晰成块
扫光 --shimmer-a↔b#ececec↔#dcdcdc / #262626↔#333#f3f4f7↔#e8ebf1 / #26272b↔#3a3c43扫光两端内部对比 1.16→1.22，灰度已提亮半档减轻沉感
等待占位 --color-placeholder#e9e9e9 / #262626#f0f2f6 / #25262b带微冷相区别于纯白页底
失败态描边/前景#d9d9d9·text-tertiary / #363636#dde2ea·#858b96 / rgba(白15%)·#9499a3静止底+描边，与扫光态区分
连带影响（落地时需一并核对）：① sticky-header 玻璃底、hero 区、各页大面积 rgba(0,0,0,.0x) hover 层在纯白页底上的观感；② 暗色页面底由 #141414 → #0f0f11，surface/#262626 系浮层级差同时重排；③ index.html 启动骨架填充需同步交接色；④ 皮肤 skins.css（mechanical/retro）不吃这套灰阶则不动。
依据：YouTube 网页版浅色 body = 纯白、模块/骨架用 #f0f1f2→#e2e5ea 级浅灰；iOS「分组背景」语言 = 白页上垫浅灰容器；骨架灰与页面底**跨语义**（页面不灰、灰即占位）是第一层解法，比在灰里调 ΔL 更稳。
