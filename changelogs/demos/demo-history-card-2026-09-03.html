③ 批量栏「始终贴浏览器底部」= sticky 不是 fixed

悬浮栏渲染在全局滚动容器 .app-shell__scroll（带 contain:layout）内——position:fixed 会以该容器为包含块，滚动时随内容滚走（实测 900px 时 top 变负）；改用 position:sticky; bottom:var(--space-xl) + margin:auto 居中后，任意 scrollTop 下 bottom 恒定钉底。

  position: sticky; bottom: var(--space-xl);

④ 桌面 min-width 1024 全局规则

桌面 Web（视口 ≥768px 且非 app / 非 tv）以 1024px 为最小画布：窗口再窄不收缩版式，交给横向滚动条。真正的手机（<768px）与 App / TV 不受影响。已写入 index.css 全局规则 + variables.css token。

@media (width >= 768px) {
  html:not([data-device="app"]):not([data-device="tv"]) body{
    min-width: var(--layout-min-width-desktop, 1024px);
  }
}
↓ 拖动下方滚动条 = 视口被压到 1024px 以下的效果：画布保持 1024px 宽，出现横向滚动条。真正移动端 / App / TV 不受此规则影响。
