三、新增 token（纯比例驱动，无 clamp / 无断点档位）

/* :root（≥768 段2 块内），--page-pad-x 分档：默认 token / ≥1280且<1920=60px / ≥1920且<2560=80px / ≥2560=140px */
--page-pad-x: var(--space-md);
@media (width >= 1280px) and (width < 1920px) { :root { --page-pad-x: 60px; } }
@media (width >= 1920px) and (width < 2560px) { :root { --page-pad-x: 80px; } }
@media (width >= 2560px) { :root { --page-pad-x: 140px; } }

/* hero-bili 专用（作用在 .hero-bili 容器上） */
--hero-banner-h: calc((min(100vw, var(--content-max-w, 2200px)) - 2 * var(--page-pad-x, 0px)) * 0.2727);
--hero-side-w:   calc((min(100vw, var(--content-max-w, 2200px)) - 2 * var(--page-pad-x, 0px)) * 0.56);
--hero-main-gap: 10px;  --hero-side-gap: 10px;
--hero-title-size: 13px;  --hero-card-radius: 8px;
  • 锚定内容宽 → banner 宽高比恒定 1.59:1、banner:右栏恒定 43:56，任何视口自动成立。
  • 1440 定稿点：banner 571×360 / 右栏 739 / 单卡 240×175（已实测）。
  • 注意 --content-max-w 对齐项目真实 token --layout-content-max-width: min(100%, 2200px)，落地时统一引用一个。

五、交互行为（逐条验收）

  • 轮播：5s 自动轮播、左右箭头 hover 显现、9 圆点；轮播/切图不重绘右侧卡片（renderBanner 内禁止调 renderCards）。
  • 换一换：feather refresh-cw 图标；点击后 is-spinning 类触发 hero-refresh-spin 0.6s 转一圈；防抖 = 动画锁：is-spinning 未移除前点击直接 return（0.6s 内最多触发一次）；prefers-reduced-motion 下动画时长归零但仍保留锁语义。
  • banner 双按钮：沿用原 hero-banner__cta 样式 token（--color-surface-elevated 白底 / --color-danger 红底继续播放）；继续播放仅 historyMap.has(String(item.id)) 时渲染（与 HeroBanner.tsx:957 现逻辑一致）；两按钮 e.stopPropagation() 后分别走 onContinuePlay(item) / onItemClick(item)。
  • 右侧卡点击跳详情：事件委托在卡片容器上，e.target.closest('.hero-side-card') → navigate(`/detail/${item.vodId ?? item.id}`)（项目已有 /detail/:id 路由）；键盘 Enter 等价触发（卡片 tabindex=0）。
  • 收藏不冒泡：委托内先判 closest('.hero-side-card__fav')，命中则 toggle('is-on') + e.stopPropagation() + return（不得进入跳转分支）；真实落位调 useUserStore 收藏接口。
  • 标题跑马灯：仅 is-overflow（测量 seg 宽 > 容器宽）悬浮滚动，双段等长无缝循环 4.5s。
