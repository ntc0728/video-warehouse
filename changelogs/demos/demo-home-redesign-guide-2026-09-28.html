01

市场调研 · 用户与客厅大屏的现状

数据来自 2026-09 检索的公开报道与行业统计，用于回答一个前置问题：重设计要把「谁、在什么屏幕、什么时间」放在第一优先级。

Roku · 2026
十年首次

Roku 十年来首次改版首页：个性化 Top Picks、快捷入口、继续观看置顶——行业信号是「决策路径压缩」，让第 1 屏就回答「接下来看什么」。

Hub · 退订归因
36%因 UX 退订

36% 用户因体验（而非内容）退订，25 岁以下升至 43%；用户在 90 秒内找不到内容即流失。首页必须在一次注视内给出「继续看 / 今晚推荐 / 筛选入口」。

10-foot · 客厅规范
≥14pt

电视端正文 ≥14pt、单屏 8–15 条横滚行、遥控器焦点必须高对比可见——决定大屏字号与密度的地板，不是审美偏好。

网络视听 · 用户
10.99 亿日均 201 分钟

全国网络视听用户 10.99 亿，人均单日使用 201 分钟；在线视频 App 活跃 8.15 亿，长视频 7.52 亿，20–29 岁与本科以上占约 86%。

智能电视 · 客厅
3.36 亿日均 331 分钟

智能电视激活 3.36 亿台、日均开机 331 分钟，超六成用户表示大屏时长在增加；TV 端留存比移动端高 30–40%。大屏不是「小屏的放大」，是第一战场。

微短剧 · 增量
6.62 亿日均 129 分钟

微短剧用户 6.62 亿、人均单日 129 分钟，下沉市场是主战场；竖屏 9:16 内容需要与横版长视频同屏共存的入口。

面板 · 分辨率
4K >60%

4K 电视出货占比已超 60%，2200/2560 宽的桌面与大屏浏览器不再是边缘场景；CSS 增列、字号抬档、留白放大必须是系统性规则。

内容结构 · 用户
下沉 62%

下沉市场用户占比约 62%，设备与网络条件参差——渐变占位、可降级的动效、无网络依赖的骨架比远程大图更稳。

02

用户画册 · 四类目标用户

每个画像对应一款 demo：谁的痛点最尖锐，谁就决定那款风格的信息架构（不是换配色）。

客厅主理人

42 岁 · 三四线 · 55" 4K + IPTV · 日均开机 331 分钟

  • 遥控器操作，讨厌细小目标与隐藏菜单
  • 先「继续上次的」，再「全家都能看的」
  • 对频繁改版最敏感，要稳定的位置记忆
→ S2 磁贴控制台

片库收藏家

27 岁 · 21:9 + 4K 双屏 · 重度索引与筛选

  • 要列数、密度、榜单、评分一眼可扫
  • 键盘/焦点可达，宽屏宁可多列不留白
  • 习惯「工具型」界面而非杂志式排版
→ S3 片库工作台

下班追剧族

24 岁 · 笔记本 1440/1920 · 21:00–24:00

  • 90 秒内决定看什么，失败就切平台
  • 「今晚看什么」比「海量片库」更值钱
  • 继续观看进度跨设备要准确
→ S1 放映室

短剧原住民

下沉市场 · 手机为主 + 电视投屏 · 日均 129 分钟

  • 竖屏 9:16、单集 2–8 分钟、按集连播
  • 类型即口味，靠色/标签快速联想
  • 更新追更提示比编辑推荐更有驱动力
→ S4 光谱

四款风格 Demo

四种信息架构，而非四种配色。点右下角「打开」在新标签查看完整大屏效果，回来再调窗口宽度观察断点。

S1 · 放映室 Cinema

暗色 · 决策式影院 · 对应「下班追剧族」

主张：首页 = 一次决策。Hero 舞台给「继续观看」，右侧「今晚决策栏」给三选一，横滚行只做候选而不是主角。首屏填满不留空，暗色对齐片源画面本身。

暗色 #0b0b0eHero + 决策栏进度跨端提示决策 90 秒

S2 · 磁贴控制台 Tiles

亮色 · 遥控器友好 · 对应「客厅主理人」

主张：大目标 + 稳定位置。磁贴即导航，基础字号 16 → 21 随大屏抬档，焦点环 3px，数字键 1–9 直达任意磁贴——把 10-foot 规范落成可验证的规则。

大磁贴字号 16→21数字键直达焦点高对比

S3 · 片库工作台 Library

亮色 · 高密度三栏 · 对应「片库收藏家」

主张：超宽屏是资产。左 rail（≥1024 图标 / ≥1440 展开文字）+ 中片库 auto-fill 增列 + ≥1920 右榜单栏同屏在场；舒适/紧凑密度切换，右下 chip 显示实测列数。

S4 · 光谱 Spectrum

亮色 · 类型色 + 竖屏短剧 · 对应「短剧原住民」

主张：类型色即导航。色谱 chips 直接过滤精选行，横版长视频与 9:16 短剧同屏并存（≥1920 竖版 3→4 张），一行回答「我今晚的口味」。
