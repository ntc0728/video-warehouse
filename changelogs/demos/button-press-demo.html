Button 按压反馈方案对比

鼠标按住（或键盘聚焦后空格）每个按钮即可看到效果 · 重点对比右侧居中箭头的"下沉/掉下去"问题

方案0：当前全局 有 bug

button:active{transform:scale(.97)} 无差别覆盖。右侧箭头靠 translateY(-50%) 居中，按下时 scale 顶掉居中 → 箭头瞬间掉下去（异常下沉）。

按住右侧箭头看它"掉下去"

方案1：独立 scale/translate 修复冲突

居中用 translate:0 -50%、按压用 scale:.92，二者独立互不覆盖。箭头不再掉下去，仍可保留按压手感。

按住右侧箭头：居中稳定 + 轻微下沉

方案2：opt-in .pressable 白名单

撤销全局规则，仅给需要的按钮加 .pressable 才生效，且带 prefers-reduced-motion 降级。不该触发的地方不触发。

方案3：纯阴影/亮度 零位移

只动 box-shadow:inset + filter:brightness，不缩放不位移，绝不与任何 transform 冲突，天然适配 reduce-motion。

方案4：水波纹 ripple 品牌感

点击处扩散水波纹 + 轻微背景压暗，替换 scale，更有辨识度。基于现有 RippleButton 模式。

方案5：拟物 3D 按下 立体键

静止有底部"厚度"阴影，按下时整体下沉 3px 且厚度收起，像真实物理按键。比纯 scale 更有按压实感。

方案6：弹性回弹 spring

松手时用弹性缓动 cubic-bezier(.34,1.56,.64,1) 回弹过冲，按钮会"Q 弹"一下，适合年轻化/娱乐向产品。

方案7：键盘式内陷 内容位移

外壳不动，仅内部文字下移 2px + 内阴影，模拟机械键盘帽被按下的感觉。完全不影响外部布局。

方案8：描边脉冲 外圈扩散

按下时从按钮边缘扩散一圈光环，自身不缩放不位移，醒目且零定位冲突。适合图标/主操作。

方案9：亮起闪 零位移

按下时背景变主色 + brightness(1.18) 亮一下，无缩放无位移，最克制也最稳，适合需要低调反馈处。

对比要点：① 方案0 的箭头按下会"掉下去"（bug），方案1 修复了它；② 方案2 只有显式加类的按钮才动；③ 方案3 完全不动位置最稳；④ 方案4 用波纹替代缩放更有特性。可按 F12 → 渲染 → 模拟 prefers-reduced-motion 验证方案2降级。
