## 2. 播放器六项问题调研结论（只调研不改码，附修复建议）

- ① 更多设置弹窗修改后不关闭：chip 类走 `selectAndClose`（应用+toast+关闭），Switch 类「后台听视频/镜像翻转」onChange 漏调 `onClose()`；字幕开关开启时刻意不关（便于进入子设置）。
- ② 后台听视频：**未实现（假开关）**——`usePlayerStore.backgroundPlay` 仅 UI 存取，全仓库零消费点；`mediaSession` API 全仓库零引用。方案：P1 MediaSession 集成 → P2 iOS ManagedMediaSource/后台保活 → P3 Android 原生前台服务。
- ③ CMS 源折叠面板 tab 文本溢出：桌面 `.player-cms-list` 固定 3 列 grid 均分 + `.player-cms-name` `overflow:hidden+ellipsis`（Player.css:240）；移动端 `.player-cms-item` `max-width` 钳制 1/6 行宽（Player.css:797 区块，注释声称「不截断」是错的）。
- ④ 桌面切页签画面冻结：`usePlayerCore.ts:162-180` 已有 Issue2 修复（95c36a1，**未推送**），但手段无效——`video.play()` 幂等 no-op、同值 `style.transform` 重写不触发重绘；且 video 带 `transform`（镜像/4:3/16:9）或 `filter`（色彩调整）时是合成效果层（PlayerCore.tsx:58-71），Chromium 后台恢复不栅格化的经典冻结面。后台期间画面冻结为浏览器固有行为，Web 无法让隐藏页签持续渲染。
- ⑤ 预加载：`useNextEpisodePreload` hook 已实现且接入（Player/index.tsx:190），URL 与实际播放完全一致（同 `sources.find(isDefault)||sources[0]` 规则），vitest 8 用例全过；但只预拉「清单+首分片」且依赖源站缓存头，体感收益有限——「没实现」是效果误判，「实现了」是效果夸大。
- 涉及文件：无（调研报告输出至会话）

## 3. 播放器四项修复 + 画面比例重构

- 日期：2026-08-31
- 问题：① 移动端更多设置弹窗 Switch 类改完不关；② CMS 源 tab 文本被截断；③ 桌面切页签画面冻结；④ 后台听视频是假开关；⑤ 画面比例实现不合理。
- 修复：
  - **① MobileMoreSheet**：后台听视频/镜像翻转/字幕开关三处 Switch 的 onChange 补 `onClose()`（与 chip 类 `selectAndClose` 行为一致）。字幕开关不再「开启不关」——改完即关，需进子设置再重开。
  - **② Player.css CMS tab**：基础规则 `grid repeat(3,1fr)` → `flex flex-wrap`，删除移动端/app 媒体查询的 `max-width: 1/6行宽` 钳制副本（旧注释「按钮文字不截断」与实际行为不符，已废弃）。tab 按内容自适应宽度，放不下自动换行。
  - **③ usePlayerCore 冻结修复**：visibilitychange 兜底从「同值重写 transform + offsetWidth」（不产生样式变化、对合成层无效）改为「追加 translateZ(0)，两帧后还原」——制造真实样式变化强制合成层失效重建。
  - **④ useMediaSession hook**：新建，锁屏媒体卡片（标题/副标题/进度）+ 媒体键 play/pause/seekbackward/forward/previoustrack/nexttrack；`backgroundPlay` 开关驱动（关闭则不注册元数据）。usePlayerCore 接入、UniversalPlayer 接线（点播=影片名+集名，IPTV=频道名）。
  - **⑤ PlayerCore 画面比例重构**：4:3/16:9 从 `objectFit:contain + translateX/Y(-50%)` 改为 `objectFit:fill + margin:auto`。理由：① contain 只加黑边、比例选择不改变画面几何，无法纠正 CMS 源 DAR 元数据错误；② 移除 translate transform 减少视频合成层（与冻结根因相关）。镜像 scaleX(-1) 保留。
- 涉及文件：`useMediaSession.ts`(新)、`usePlayerCore.ts`、`PlayerCore.tsx`、`MobileMoreSheet.tsx`、`UniversalPlayer.tsx`、`Player.css`、`player.spec.ts`
- 测试：M02/M03 通过（字幕开关行为变化已同步更新断言）；M07/M10 失败经 git stash 验证为既有 flaky 像素断言（改动前已失败，非本次引入）
- 构建：`npm run build` 通过
