## 3. HeroBanner 缩略图骨架错位修复：骨架态缩略图列从左上角回到右侧

- 日期：2026-08-26
- 问题：进入首页（冷加载）或首次进入分类时，HeroBanner 右侧缩略图列的骨架图跑到最左侧；真实缩略图列却在右侧 → 「骨架在左、实图在右」的位置跳变。
- 根因（两条独立路径、同一症状）：
  1. 首页冷加载骨架 `.home-skeleton-hero`（Home.css）：容器**没有 `display:flex`**，其 `__banner` / `__content` 均 absolute，唯一在正常文档流的 `__thumbs` 被推到左上角。
  2. HeroBanner 空/骨架态（`!displayItems.length`，HeroBanner.tsx L450-476）：真实态有 `.hero-banner__main`（`flex:1 1 0`）占满主区、把 `__thumbs` 挤到右侧；骨架态分支只渲染 `__bg-wrapper` / `__content` / `__thumbs`，`__thumbs` 成为**唯一在流的 flex 子项** → 最左。
- 旧逻辑：`__thumbs` 在 flex row 容器里靠「前方 flex:1 主区」推右——主区缺失（骨架/空态）即贴左。
- 新逻辑：
  - Home.css `.home-skeleton-hero` 补 `display:flex; flex-direction:row; align-items:stretch`；`__banner` 从 `position:absolute; inset:0` 改为 `position:relative; flex:1 1 0; min-width:0; height:100%; overflow:hidden`（严格镜像 `.hero-banner__main`，shimmer 背景/动画不变）→ 骨架态下 `__banner` 占满主区、`__thumbs` 回到右侧。
  - HeroBanner.css `.hero-banner__thumbs` 补 `margin-left:auto`：真实态 `__main` 已 flex:1 撑满、auto 无副作用；骨架态（无 `__main`）auto 把缩略图列推回右侧。未在 TSX 补空 `.hero-banner__main`——避免遮住 bg-placeholder + mask，保持 DOM 最小改动。
