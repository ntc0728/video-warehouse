# 2026-08-18

## 播放器交互修复计划落地（docs/player-fix-plan.md：C1-C5 冲突 · G1-G10 缺口 · R1-R6 冗余）

- 日期：2026-08-18
- 问题：`docs/player-interaction-audit.md` 审计出播放器交互冲突/缺口/冗余共 20 余项，此前 8-17 已修复一部分（commit 8a1c213），本次按 `docs/player-fix-plan.md` 补齐剩余项并解决计划内部矛盾。
- 冲突修复（C）：
  1. **C1 播放键语义统一**：ControlBar PlayButton disabled 由 `(isBuffering && !isPlaying) || isPlayerLoading` 改为 `isPlayerLoading && !isReadyToPlay`；注释与 togglePlay（缓冲中不暂停）一致。计划内部「缓冲中按钮可暂停 vs togglePlay 缓冲守卫」矛盾按字面方案裁决：缓冲中不暂停为单一真相。
  2. **C2 静音统一**：`usePlayerCore` 新增 `toggleMute()`（当前有声→记 `mutedVolume` 再静音；静音→恢复记忆值，无记忆兜底 1）；VolumeControl 喇叭、键盘 M（点播/IPTV 两分支）、MobileMoreSheet 静音钮全部改走它，消除「0↔1 满音量」与「0↔记忆值」双路径语义不一致。
  3. **C3 seek 策略统一**：键盘 `debouncedSeek` 守卫 `isBuffering || isPlayerLoading` → `isPlayerLoading && !isReadyToPlay`（缓冲中允许 seek，与进度条拖拽一致）；`useLongPress` onSeek 由直接改 `video.currentTime` 改为走 `playerCore.seek`；长按禁用由 isBuffering 改为 `isPlayerLoading && !isReadyToPlay`。N5 同步放开 useLongPress 的 `mode==='iptv'` 早退（IPTV DVR 窗口内同样支持长按 seek）。
  4. **C4/R2 全屏统一**：`lib/fullscreen.ts` 新增 `toggleFullscreen(container, videoElement?, hasError?)`；三处入口（FullscreenButton / F 键 / 双击 usePlayerClickHandler）共用；hasError 守卫经 FullscreenButton hasError prop（PlayerHeader/ControlBar 透传）三处一致。
  5. **C5/R4 渲染异常边界**：PlayerErrorBoundary 新增 `onRetry` prop（重试递增 retryCount 触发重建），错误 UI 加「重试」按钮；注释明确仅兜底渲染异常、不处理播放错误（后者走 hasError → PlayerCore overlay）。
- 缺口补齐（G）：
  1. **G1 进度条缩略图**：新增 `ControlBar/ThumbnailPreview.tsx`（可选 `thumbnails` 源 + `timeToUrl`；无源降级为时间戳文本），ProgressBar 新增可选 `thumbnails` prop，tooltip 内嵌预览。
  2. **G2 音量条全模式**：VolumePopup 渲染条件 `mode==='iptv'` → 全模式；ControlBar 新增 `onVolumePopup` prop，VolumeControl 滑杆/喇叭变化时调 `showVolumePopupWithTimer`（键盘/遥控器原有路径不变）。
  3. **G3/G6 移动端更多设置**：MobileMoreSheet 新增音量卡片（百分比滑块 + 静音钮）+ 画中画项（`document.pictureInPictureEnabled` 约束、`isPiP` 显「开启/退出」）。
  4. **G4 切清晰度提示**：`switchLevel` 内 `playerToast('清晰度：'+label)`；`getResolutionLabel`（'1080p' 小写）抽到 `lib/utils.ts`，ResolutionSwitch / MobileMoreSheet / switchLevel 三处共用（HLSAdapter 的 getQualityLabel '1080P' 不同不动）。
  5. **G5 IPTV 自动恢复扩展**：维持方案 A（现状，仅手动重试），待产品确认，未改代码。
  6. **G7-G10 移动端亮度/音量纵向滑动**：新增 `hooks/useTouchGesture.ts`（原生 touch 监听，touchmove `{passive:false}` 以便 preventDefault；左半屏=亮度、右半屏=音量；8px 纵轴阈值锁方向；上滑增值；亮度 0.1-2 写 `video.style.filter=brightness()`，音量 0-1 走 playerCore.setVolume）+ `MobileUI/BrightnessVolumeIndicator.tsx`（柱状图+图标+百分比，松手 1.2s 淡出）。仅 `isMobileLayout && mode==='video'` 挂载。与 useLongPress 通过共享 `verticalGestureActiveRef` + 10px 位移取消 pending 长按协调。
- 冗余清理（R）：
  1. **R5 控制栏可见性单一出口**：`usePlayerControls` 新增 `syncAutoHide({isPlaying,isBuffering,hasError})`；UniversalPlayer 错误状态 effect 改走它，消除散落的 setControlsVisible/clearTimeout 重复逻辑。
  2. **R6 循环模式常量**：`LOOP_CYCLE` 从 useKeyboardShortcuts + LoopButton 本地定义收敛到 `lib/utils.ts` 共享。
