## 设置页 tab 切换抖动 + 滚动条残留
- 日期：2026-08-13
- 问题：桌面端点击 settings-tabbar 按钮页面抖动；内容变矮后右侧自定义滚动条 thumb 残留。
- 旧逻辑：内容区 `key={activeTab}` 整体重挂载 + `settings-content-in` 动画（fadeIn + translateY(8px)）；`.settings-tab` 字重 500→600 激活变化导致 tab 宽度变化 → flex-wrap TabBar 整行重排；`OverlayScrollbar` 仅 `ResizeObserver` 观察滚动容器自身（高度恒定 = 视口，永不触发）+ scroll 事件——内容变矮且 scrollTop 未动时无任何信号，thumb 残留。
- 新逻辑：
  - 内容区改「访问过才挂载 + display 切换」：`visitedTabs` Set 记录已访问 tab，pane 常驻、激活 pane 播放纯 opacity 淡入（`.settings-content__pane--active`，keyframes 去 translateY）；未访问 tab 不挂载（各 tab bootstrap 有模块级 guard，副作用幂等）。移动端 SubPage 结构不变（`renderContent` → `renderTab(key)` 参数化）。
  - `.settings-tab` 字重统一 600，激活态仅靠主色背景 + 反色文字区分。
  - `OverlayScrollbar` 增加 `MutationObserver`（childList + subtree + attributes style/class）监听内容 DOM 变化——Keep-Alive display 切换、tab 切换、异步渲染等「内容变了但 scroll/RO 不触发」场景据此重算 thumb。
- 涉及文件：`src/pages/Settings/index.tsx`（visitedTabs + renderTab + pane 渲染）、`src/pages/Settings/Settings.css`（`.settings-content__pane` + 纯 opacity keyframes + 字重 600 + padding 迁移）、`src/components/common/OverlayScrollbar.tsx`（MO）
- 关联 Demo：无独立 Demo（dev server 设置页桌面端切 tab 即预览）
- 构建：`npm run build` 通过；settings.spec.ts 24 用例通过（SET-052 为存量失败：`uncheck()` 操作 CSS 视觉隐藏 input，stash 基线复现同样失败，与本次改动无关）

## GitHub Release 缺 APK assets（CI 链路修复）
- 日期：2026-08-13
- 问题：所有 release 只有源码 zip/tar.gz，无 APK。根因：release-please 用默认 GITHUB_TOKEN 创建 Release → GitHub 安全限制禁止 GITHUB_TOKEN 事件递归触发其他 workflow → 独立 `release-android.yml` 的 `on: release: types: [published]` 是死链（Actions 页实证该工作流 0 runs）。
- 旧逻辑：`.github/workflows/release-android.yml` 监听 release published 构建上传；`release-please.yml` 仅 release-please action。
- 新逻辑：
  - `release-please.yml`：release-please action 加 `id: release`，新增 `build-apk` job（`needs: release-please` + `if: needs.release-please.outputs.release_created == 'true'`），checkout `tag_name` → 构建 → `gh release upload "$TAG" kinoTv-v${TAG#v}.apk --clobber`（同工作流 needs 级联，无事件递归限制）。
  - `release-android.yml`：加 `workflow_dispatch`（输入版本号）作手动补传入口（补传 v1.6.0/v1.7.0），保留 `release: published` 触发；tag 解析 `inputs.version` 优先。
- 涉及文件：`.github/workflows/release-please.yml`、`.github/workflows/release-android.yml`
- 关联 Demo：无（CI 类改动；下次发版 + Actions 手动 dispatch 验证）
- 构建：不涉及（workflow 文件）
