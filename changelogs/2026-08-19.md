- 日期：2026-08-19
- 问题：投屏功能缺三类能力——① Web Cast 空态点「重新选择设备」会先闪雷达（`startWebCast` 开头无条件 `setView('searching')`）再弹系统选择器；② 安卓 App 无投屏权限前置流程（SSDP 组播受 Android 13+ NEARBY_WIFI_DEVICES 约束，无授权提示/引导）；③ E2E 未覆盖无 Chromecast 空态、重选直接重开、连续点不闪雷达、setSource URL、权限授权/拒绝。
- 旧逻辑：
  - `CastSheet.tsx:55` `startWebCast` 无条件 `setView('searching')` → 空态点「重新选择设备」(`:174` 调 `startWebCast()`) 先渲染雷达再 `requestSession`，观感闪烁。
  - `castService.ts` `CastBridge` 无 `ensurePermission`/`openAppSettings` 方法；安卓补丁 `CastBridgePlugin` 无权限检查。
  - E2E：`player.spec.ts` 只有 PLAYER-M14/M15（按钮可见 + mock Cast 全流程），无空态/重选/权限用例。
- 新逻辑：
  1. **闪烁修复**：`startWebCast(showSearching = true)` 增加第二参；空态「重新选择设备」按钮改调 `startWebCast(false)` → 不 setView('searching')，直接重开系统选择器。
  2. **权限流程**：`CastBridge` 契约加 `ensurePermission(): Promise<'granted'|'denied'>` + `openAppSettings(): Promise<void>`；`castService` 加 `ensureCastPermission()`/`openCastAppSettings()`（桥未实现时返回 'unsupported'，前端按旧流程继续，向后兼容老 App/测试 mock）。`CastSheet` 新增 `permission` 视图：native 打开时先 `ensureCastPermission()`，denied → 显示🔒「需要投屏权限」+「去设置授权」按钮（调 `openAppSettings` 跳系统应用设置页）；granted/unsupported → 原搜索流程。Web Cast 不走权限前置（Google Cast 系统选择器自带）。
  3. **安卓原生同步**：`CastBridgePlugin` 加 `ensurePermission`（API 33+ 检查/请求 NEARBY_WIFI_DEVICES，`@PermissionCallback` 回调结果；老系统直接 granted）+ `openAppSettings`（`Settings.ACTION_APPLICATION_DETAILS_SETTINGS`）；`@CapacitorPlugin` 注解加 `permissions = { @Permission(...alias="nearbyWifi") }`；`MainActivity` shim 加两方法；`patch-android-dlna.ps1` 追加 `NEARBY_WIFI_DEVICES` 权限。
  4. **E2E**：新增 `injectMockCastSdk()` helper（`addInitScript` 注入 `window.cast.framework` + `window.chrome.cast.media`，行为由 `window.__castMock.mode` 控制 + `requestSessionCalls` 计数）。新用例：
     - PLAYER-M16：无 Chromecast（mode='null'）→ 空态「未选择投屏设备」+「重新选择设备」按钮。
     - PLAYER-M17：重选直接重开（mode null→session）→ requestSession 调用数=2、点击后 `.up-cast-radar` 数量 0（不闪雷达）。
     - PLAYER-M18：连续点 3 次「重新选择设备」→ 每次雷达 count 0、仍停空态、requestSession 总调用=4。
     - PLAYER-M19：native 权限被拒 → 「需要投屏权限」+「去设置授权」→ 点按钮 openAppSettings 调用数=1。
     - PLAYER-M20：native 权限授予 → 正常出设备列表。
     - PLAYER-M21：全链路 discover→connect→setSource，断言推送 URL 非空且 `^https?://`。
