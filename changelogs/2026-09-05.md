## Demo v3：banner 宽度也加档位（14:28）

**用户反馈**：banner 宽度太大（1920 视口下 1fr 撑到 ~1500px），要求也加档位调节。

**改动**（`changelogs/demos/demo-hero-bili-style-2026-09-05.html`）：
- 新增 CSS 变量 `--hero-banner-w`（默认 **640px**）+ `--hero-justify`（默认 `start`）
- `grid-template-columns` 由 `minmax(0,1fr) var(--hero-side-w)` 改为
  **`var(--hero-banner-w) var(--hero-side-w)`** + `justify-content: var(--hero-justify)`
- 面板新增两组：
  - **BANNER 宽度**：`520 / 580 / 640(推荐) / 720 / 自适应 1fr`
  - **整体对齐**：`左对齐 / 居中`（定宽后右侧余量的归属）
- 读数区追加：`hero 占宽 / 可用宽 / 余 __px`

**定宽后的副作用（需用户拍板）**：banner 定宽后 hero 区不再撑满内容区，右侧出现余量——
- 左对齐：hero 靠左、右侧留白（与原 hero 观感一致，但大屏右侧空一块）
- 居中：hero 整体居中、两侧均分留白
- 自适应 1fr：回到撑满（即 v2 行为，大屏下就是用户嫌太宽的那档）

**当前默认组合**：banner 640×280（比例 2.29:1）+ 右栏 380（3 行×2 列，单卡 ≈165×85）+ 左对齐。

## Demo v4：修复右侧卡片严重挤压（14:34）

**问题**：用户反馈「右侧 card 严重挤压」。
**根因量化**：右栏 380 − shuffle(50) − gap(8) = 网格 322 → 2 列单卡仅 **157px**；
再扣 padding(8) + 图片 52%(82) + gap(8) → **文字区只剩 ~64px**（13px 字号一行仅 4~5 字）。
横版卡（图左文右）单卡宽度低于 ~220px 必然挤压。

**修复**（`changelogs/demos/demo-hero-bili-style-2026-09-05.html`）：

| 项 | v3（挤压） | v4 |
|---|---|---|
| 右栏总宽 `--hero-side-w` | 380px | **540px**（档位改 420/480/**540**/600，标注「横版卡需 ≥480」） |
| 卡内图片 | `52%` 百分比（卡越宽图越大，挤占文字） | **`--hero-media-w: 104px` 定宽**（档位 88/**104**/120，卡片越宽 → 文字区越大） |
| 单卡尺寸 | 157×88，文字区 64px ⚠ | **≈237×88，文字区 ≈117px**（一行 ~9 字，2 行 18 字） |
| grid 列定义 | `var(--hero-banner-w) var(--hero-side-w)` | `minmax(0, var(--hero-banner-w)) var(--hero-side-w)`，空间不足时**优先压 banner，保住右栏卡片宽度** |

**读数区增强**（实时判定挤压）：
- 新增「文字区 __px」读数，< 90px 时标红 `⚠ 挤压`
- 「hero 占宽 / 可用宽」超出可用宽时标红 `⚠ 溢出，两列被压缩`

**默认组合（v4）**：banner 640×280（2.29:1）+ 右栏 540（3 行×2 列，单卡 ≈237×88，卡内图 104×80，文字区 ≈117）+ 左对齐 → 1280 视口 hero 占 1192 / 可用 1256。

## Demo v8：换一换竖排半卡高 + 标题跑马灯 + banner 轮播不刷新右卡（15:2x）

**用户反馈**：① 换一换**文本竖向排列** ② 换一换**高度 = 单卡一半** ③ 卡片**标题不换行、悬浮跑马灯** ④ **banner 自动轮播时右侧卡片不更新**。

**改动**（`changelogs/demos/demo-hero-bili-style-2026-09-05.html` 已覆盖）：

| 项 | v7 | v8 |
|---|---|---|
| 换一换文本 | 图标在上、文字在下（`white-space: nowrap` 横向） | 文字 **`writing-mode: vertical-rl` 竖向排列**；图标仍在上（16px），结构不变 |
| 换一换高度 | `calc(... / rows)`（= 单卡行高） | **`calc(... / rows / 2)`（= 单卡一半）**，`top: 0` 仍与右栏第一行顶部对齐 → 浮于第一行右侧、半卡高 |
| 卡片标题 | `-webkit-line-clamp: 2`（两行截断） | **`white-space: nowrap` 不换行** + 标题内嵌 `.hero-side-card__title-track`（双段等长）；仅当单段文本宽度超出标题容器时给卡片加 `is-overflow`，**悬浮时 `hero-marquee` 4.5s 无缝循环**（translateX 0→-50%） |
| banner 轮播 ↔ 右卡 | `renderBanner()` 内调用 `renderCards()`，轮播/切圆点会重绘右卡 | **`renderBanner()` 移除 `renderCards()` 调用**；右卡仅在 `init()`（首屏一次）、「换一换」、`cols/rows` 滑杆变化、恢复默认时重建 → **自动轮播不再触发右卡更新** |
