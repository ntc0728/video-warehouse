# Scripts 目录

此目录用于存放项目中的脚本文件，包括但不限于：
- 自动化测试脚本 (agent-browser)
- 数据处理脚本
- 构建脚本
- 工具脚本

## 使用规范

| 脚本类型 | 命名规范 | 示例 |
|----------|----------|------|
| 验证脚本 | `verify-*.ps1` | `verify-homepage.ps1` |
| 清理脚本 | `cleanup-*.ps1` | `cleanup-logs.ps1` |
| 构建脚本 | `build-*.ps1` | `build-deploy.ps1` |
| 测试脚本 | `test-*.ps1` | `test-api.ps1` |
