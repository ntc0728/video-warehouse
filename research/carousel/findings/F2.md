# F2: Swiper v14 status assessment

## Findings

### [1] Swiper v14.0.5 is the latest release, published July 10 2026 — actively maintained by solo developer nolimits4web
- quote: "14.0.5 • Public • Published a day ago" (npm), "v14.0.5 released on July 9, 2026" (official site)
- url: https://www.npmjs.com/package/swiper
- source_type: primary
- published: 2026-07-10
- confidence: high

### [2] v14 is a ground-up TypeScript rewrite — hand-maintained .d.ts tree eliminated, declarations now emitted directly from runtime source via tsc
- quote: "In v14, src/ is now entirely .ts/.tsx. The hand-maintained .d.ts tree is gone - declarations are emitted directly from the runtime source with tsc. The types can no longer drift from the code, because they are the code."
- url: https://swiperjs.com/blog/swiper-v14
- source_type: primary
- published: 2026-06-26
- confidence: high

### [3] Zero runtime dependencies — ssr-window dependency removed, replaced with inline environment guards
- quote: "The ssr-window dependency has been removed and replaced with inline environment guards. Swiper now installs with no transitive runtime dependencies at all."
- url: https://swiperjs.com/blog/swiper-v14
- source_type: primary
- published: 2026-06-26
- confidence: high

### [4] Bundle size: ~19.6 KB gzipped (main), ~65 KB raw — modular import means hero banner would use only core + specific effects
- quote: {"gzip":19575,"name":"main","size":65295} (Bundlephobia API)
- url: https://bundlephobia.com/api/size?package=swiper@14.0.5
- source_type: primary
- published: unknown
- confidence: high

### [5] v14 dropped legacy browser support — targets Chrome/Edge 110+, Safari 16.4+, Firefox 110+ only, removing ~28% of shared DOM utilities
- quote: "Code paths and feature detection for older browsers were removed... iOS/Android-specific quirk handling is kept but simplified. If you need to support older browsers, stay on v12."
- url: https://swiperjs.com/blog/swiper-v14
- source_type: primary
- published: 2026-06-26
- confidence: high

### [6] React wrapper is first-class — exports Swiper, SwiperSlide, useSwiper, useSwiperSlide hooks, with virtual slides and slots support
- quote: "Swiper React exports 2 components: Swiper and SwiperSlide... Swiper React provides useSwiper hook to easily get the Swiper instance in components inside of Swiper"
- url: https://swiperjs.com/react/
- source_type: primary
- published: unknown
- confidence: high

### [7] Per-module type augmentation — importing Navigation/Pagination modules brings their options, methods, and events into the TypeScript type system automatically
- quote: "Each module now augments the central Swiper, SwiperOptions, and SwiperEvents interfaces. Importing a module brings its option, method, and event types along with it"
- url: https://swiperjs.com/blog/swiper-v14
- source_type: primary
- published: 2026-06-26
- confidence: high

### [8] v14 is backward-compatible — no code changes required when upgrading from v12, only tighter types and narrower browser baseline
- quote: "upgrading from v12 requires no code changes. Every option, default, event, payload, method signature, and module import behaves exactly as before."
- url: https://swiperjs.com/blog/swiper-v14
- source_type: primary
- published: 2026-06-26
- confidence: high
