## Dead ends
- dev.to blog post "best react carousel 2024" returned 404
- npm trends page provided download comparison but limited qualitative data
- Swiper SCSS compilation issues (Dart Sass) appeared in issues but less relevant to a simple hero banner use case

## Suggested follow-ups
- Investigate Embla's plugin ecosystem (autoplay, navigation, pagination) to verify feature parity with Swiper for a hero banner
- Check whether Swiper v14's TypeScript support and React wrapper maturity are production-ready for new projects
- Research bundle size comparison (Swiper is known to be large; Embla markets itself as lightweight)
